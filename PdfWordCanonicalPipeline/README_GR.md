# PDF / Word Canonical Pipeline 0.4.7

Η πύλη έχει δύο σαφώς χωρισμένες διαδρομές.

## Αυθεντικό ή κανονικό DOCX

`composite-policy auto`:

- διατηρεί native παραγράφους, πίνακες, εικόνες, OMML και ενότητες,
- ζητά από το Microsoft Word να αποδώσει τα σύνθετα groups ως πιστή εικόνα βάσης,
- διατηρεί τις OMML εξισώσεις των grouped textboxes ως editable overlays,
- παράγει αποκλειστικά `canonical-word-v1` για τον χαμηλού επιπέδου importer.

## Υλικό που ξεκινά από PDF

`composite-policy off`:

- PDF ως γεωμετρική αλήθεια,
- Mathpix Markdown ως κύρια αλήθεια περιεχομένου,
- DOCX/Mathpix assets ως δευτερεύουσα απόδειξη και δωρητής native Word μορφής,
- Markdown LaTeX donors για εξισώσεις, με DOCX OMML ως προτιμώμενη native απόδοση όταν αντιστοιχεί ασφαλώς,
- PDF crops μόνο ως fallback.

Το PDF reconstructor δεν καλεί απροσδόκητα Word COM.
Το ανακατασκευασμένο PDF→DOCX είναι επίσημο artifact της ροής και πρέπει να διατηρείται διαθέσιμο στον χρήστη, πριν ακόμη χρησιμοποιηθεί ως είσοδος για την BookWriter κανονικοποίηση.

Προτιμώμενη αρχιτεκτονική προϊόντος:

1. `PDF + Mathpix ZIP → reconstructed DOCX + report`
2. `DOCX → Συγγραφέας`

Η εισαγωγή/παρεμβολή στον Συγγραφέα πρέπει σταδιακά να περιοριστεί σε DOCX, ενώ η PDF/Mathpix επεξεργασία να αντιμετωπίζεται ως αυτόνομος μετατροπέας.

## Ανοιχτό audit συνέχειας

- Να ελεγχθεί συστηματικά ότι οι αλλαγές εναρμόνισης ακολουθούν τη νέα λογική `Markdown first`.
- Να χαρτογραφηθούν σημεία όπου ο κώδικας κρατά παλιές παράλληλες διαδρομές ή διπλές αποφάσεις από προηγούμενες εκδόσεις.
- Όπου μια απόφαση είναι ασθενής, fallback ή συγκρουόμενη, να γράφεται σε `humanReviewQueue` αντί να αποκλείεται ο χρήστης από την επιλογή.
- Τα σημεία που πιθανότερα απαιτούν πραγματική απόφαση χρήστη να προβάλλονται χωριστά σε `userDecisionQueue`, ώστε το πλήρες audit να μη λειτουργεί ως θόρυβος.
- Η DOCX εκδοχή του Mathpix παραμένει χρήσιμη ως δεύτερη γνώμη, όχι ως ανώτερη πηγή από το Markdown για περιεχόμενο.

## Περιορισμοί

- Word COM απαιτεί Windows και εγκατεστημένο Microsoft Word.
- Τα μη μαθηματικά εσωτερικά στοιχεία ενός σύνθετου group παραμένουν στην εικόνα βάσης.
- Header/footer story ranges και rotated editable equation overlays δεν καλύπτονται ακόμη.
