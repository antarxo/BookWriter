# BookWriter

## Σκοπός

Το BookWriter είναι η κοινή μηχανή παραγωγής εκπαιδευτικών βιβλίων που συνδέει κείμενο, σκηνές προσομοιώσεων, εικόνες και εκτυπώσιμη μορφή.

Δεν είναι αποθήκη εφαρμογών. Οι εφαρμογές παραμένουν ανεξάρτητες και λειτουργούν ως πηγές εκπαιδευτικού υλικού.

## Βασική αρχή

Εφαρμογή → σκηνές / δεδομένα / εικόνες → BookWriter → βιβλίο

## Δομή

- `engine/` : κοινή λογική συγγραφής, σκηνών και export
- `books/` : συγκεκριμένα βιβλία
- `applications/` : συνδέσεις με εφαρμογές παραγωγής σκηνών
- `assets/` : κοινά γραφικά και πόροι

## Πρώτο δοκιμαστικό βιβλίο

Το πρώτο pipeline θα δοκιμαστεί με το βιβλίο ΗΜ κύματος.
