# Αναφορά ενοποίησης v4.5.0 RC1

## Μία ενεργή υλοποίηση ανά λειτουργία

| Λειτουργία | Ενεργή διαδρομή RC1 |
|---|---|
| Βιβλιοθήκη | Ταξινομήσιμος πίνακας με φίλτρα και δηλωτικά metadata |
| Συγγραφή | `BookWriter/author/` |
| Ηλεκτρονικό βιβλίο | `BookWriter/reader/` |
| Renderer / canonical model / DOCX / pagination | `BookWriter/core/` |
| Παρεμβολή DOCX | Διπλός χώρος: βιβλίο αριστερά, DOCX δεξιά |
| Εκτύπωση / PDF | Μία κοινή εντολή από μενού, toolbar ή `Ctrl+P` |
| Δεδομένα βιβλίου | `BookWriter/books/<book_id>/book.json` και assets |

## Αφαιρέθηκαν από το ενεργό runtime

- Ο wizard παρεμβολής της v4.4.8 με selectors προορισμού.
- Η χωριστή προεπισκόπηση ΠΡΙΝ / ΝΕΟ / ΜΕΤΑ.
- Παλιές ονομασίες probe από τα ενεργά `author`, `reader` και `core` αρχεία.
- Probe ZIP, προσωρινά PDF, render dumps και `_inspect` φάκελοι.

## Διατηρήθηκαν σκόπιμα

- Ιστορικά στοιχεία προέλευσης μέσα στα metadata παλιών βιβλίων, όπως η έκδοση converter που δημιούργησε αρχικά το βιβλίο. Αυτά είναι provenance και όχι ενεργός κλάδος runtime.
- Το compatibility path που απαιτείται για να ανοίγουν τα υπάρχοντα βιβλία.

## Καθεστώς

Η έκδοση είναι **Release Candidate 1**, όχι ακόμη τελικό stable checkpoint. Το production σχήμα και οι κύριες ροές έχουν ενοποιηθεί, αλλά η πραγματική εγγραφή, τα backup και η παρεμβολή με σύνθετα DOCX πρέπει να επιβεβαιωθούν στον Windows φάκελο εργασίας του χρήστη πριν από τελικό tag.
